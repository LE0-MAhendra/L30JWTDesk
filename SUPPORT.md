# Support

L30JWTDesk is an open-source project maintained through GitHub.

## Get help

Before reporting a problem, install the latest version from
[GitHub Releases](https://github.com/LE0-MAhendra/L30JWTDesk/releases) and
review the usage steps in the [README](README.md).

For bugs and feature requests, open a
[GitHub issue](https://github.com/LE0-MAhendra/L30JWTDesk/issues). Include:

- operating system and version;
- L30JWTDesk version;
- steps to reproduce the problem; and
- sanitized logs or screenshots when useful.

Never include JWTs, passwords, signing secrets, private keys, keystores, or
personal information in a public issue.

## Security issues

Do not disclose vulnerabilities in a public issue. Submit them privately using
[GitHub Security Advisories](https://github.com/LE0-MAhendra/L30JWTDesk/security/advisories/new).

## Privacy

See the [Privacy Policy](PRIVACY.md) for details about local storage and
optional network access.
